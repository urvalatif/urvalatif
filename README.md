### 🚀 Featured Work

> Selected projects from my role as an AI Researcher at SaveLife.AI, plus independent work. Full details in my [CV](https://urvalatif.github.io/Urva_Latif_CV_AIML_Engineer.pdf) / [LinkedIn](https://linkedin.com/in/urva-latif).

- **🧠 AI Suite — FDA-Cleared & In-Review Imaging Detection Modules**
  Built and shipped multiple deep learning detection models across the AI Suite product line — including intracranial haemorrhage detection (NeuroICH), mammogram cancer detection (MammoSightAI), chest X-ray abnormality detection (CXRDetectAI), mammographic density classification (DenseViewAI), and CT perfusion/LVO detection (NeuroLVO).

- **🩻 RadioViewAI — Interactive Imaging Viewer & Measurement Tools**
  Integrated an open-source imaging viewer with promptable segmentation (SAM-2, nnInteractive) for 3D volumetric measurement and analysis; built the Docker-based deployment pipeline.

- **📄 RadReport — RAG-Powered Radiology Report Generation**
  Collaborated with the NLP team to curate and structure large-scale medical report datasets supporting a Retrieval-Augmented Generation pipeline (Pinecone) for automated report generation.

- **🎙️ AizaMD — Clinical Documentation & Transcription**
  Experimented with and evaluated transcription models for doctor–patient encounter audio to improve ambient documentation accuracy.

- **🤖 LLM & Multimodal Prototyping**
  Built a RAG-based document Q&A chatbot, a CLIP-style chest X-ray image-and-report retrieval system, and an LLM-driven multimodal patient-summary generator combining imaging findings with clinical notes.

- **📋 Proposal Automation Agent** *(Independent Project)*
  A self-directed agentic system (LangGraph) that automates drafting of client project proposals by pulling context from prior proposals and technical specifications.
